# Roqksa

تطبيق اجتماعي عربي للغرف الصوتية والتواصل بين الأصدقاء، مبني باستخدام Flutter.

## الحالة الحالية

المشروع في مرحلة بناء الواجهات والنموذج الأولي. بعض الأرقام والمحادثات والمقاعد والهدايا المعروضة بيانات تجريبية محلية وليست بيانات مستخدمين حقيقيين.

### الواجهات الموجودة
- شاشة دخول وإنشاء حساب تجريبية مع التحقق من الحقول؛ لا تنشئ حساباً فعلياً قبل ربط Firebase Authentication.
- الصفحة الرئيسية واكتشاف الغرف والتصنيفات والبحث.
- شاشة الغرفة الصوتية التجريبية، والمقاعد وطلبات الصعود والدردشة والهدايا والتفاعلات المحلية.
- شاشة ملف شخصي قابلة لتعديل الاسم الظاهر والنبذة محلياً.
- شاشة رسائل تجريبية مع إمكانية فتح محادثة وإضافة رسائل محلية.
- تنقل عربي من اليمين إلى اليسار.

## تشغيل المشروع

يتطلب تثبيت Flutter بإصدار stable وDart المتوافق مع القيود الموجودة في `pubspec.yaml`.

```bash
flutter pub get
flutter analyze
flutter run
```

لبناء نسخة الويب:

```bash
flutter build web --release
```

## الخدمات التي لم تُربط بعد

- Firebase Authentication لتسجيل وإنشاء الحسابات.
- Cloud Firestore أو خدمة خلفية لحفظ الملفات الشخصية والمحادثات والغرف.
- Agora أو مزود صوتي مناسب لتفعيل الصوت المباشر.
- تخزين الصور ومقاطع الفيديو والحالات.
- إشعارات الدفع وإدارة الإشعارات.
- نظام الهدايا والعملات والدفع الآمن والإشراف والحظر.

لا تُعد أي من هذه الخدمات مفعّلة بمجرد ظهور واجهتها. يلزم إعداد المشاريع والمفاتيح السرية وقواعد الأمان واختبارها قبل الإطلاق.

## الفحوصات الآلية

يوجد سير عمل GitHub Actions في `.github/workflows/flutter.yml` لتشغيل `flutter analyze` واختبارات الواجهات `flutter test` وبناء الويب `flutter build web --release` عند الدفع إلى فرع `main` أو فتح طلب دمج.

## الأمان والإطلاق

قبل الإطلاق العام يجب إعداد قواعد صلاحيات الخادم، والتحقق من هوية المستخدم، وحماية البيانات، وسياسة الخصوصية، ومراجعة آليات الإبلاغ والحظر والإشراف. لا تضع مفاتيح الخدمات السرية داخل ملفات Dart أو المستودع العام.

## بناء نسخ Android وiPhone

يتضمن GitHub Actions الآن مهمتين إضافيتين لإنشاء منصات الهاتف أثناء الفحص:
- بناء ملف Android بصيغة APK للإصدار التجريبي.
- إنشاء مشروع Android وiOS الأساسي وإرفاق مجلدي المنصتين كملف ZIP ضمن عناصر تشغيل GitHub Actions.
- تجربة بناء iOS على جهاز macOS باستخدام `--no-codesign`.

للوصول إلى الملفات: افتح تبويب **Actions** في المستودع، ثم اختر أحدث تشغيل ناجح لسير العمل، ونزّل العناصر المسماة `roqksa-android-apk` و`roqksa-mobile-platforms`.

**ملاحظة مهمة:** مجلدا Android وiOS يُنشآن حالياً أثناء سير العمل ولا يُحفظان بعد في جذر المستودع. ملف iOS الناتج دون توقيع ليس جاهزاً للتثبيت على iPhone؛ يلزم لاحقاً إعداد توقيع Apple وحساب المطور وشهادات التوزيع. كما أن APK الحالي نسخة واجهات تجريبية، وليس تطبيقاً متصلاً بخدمات الحسابات أو الصوت أو الرسائل الحقيقية.
